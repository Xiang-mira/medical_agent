# Compatibility Wrappers

Model-specific compatibility entry points retained for existing integrations.

| File | Model |
| --- | --- |
| `atlasnet_wrapper.py` | ATLAS-Net |
| `epai_wrapper.py` | ePAI |
| `unest_wrapper.py` | UNEST |
| `vista3d_wrapper.py` | VISTA3D |

The registry-driven runtime is implemented under
`agent-harness/cli_anything/medai/core/` and `scripts/`.
