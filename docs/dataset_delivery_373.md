# 373 Label Repair And 100-Case Label Delivery

This workflow has two independent deliveries:

- `rename_delivery/`: safe filename-only repair for existing masks.
- `generated_labels_100cases/`: validated new masks generated by the existing Teacher run-loop.

Canonical 373 target source:

```bash
TARGET_CONFIG=configs/student_3d_prompt_target_organs.json
```

The broader hierarchy file `configs/organ_taxonomy.json` currently has 384 organs and is not used as the 373 delivery target list.

## A. HPC Pull

```bash
source ~/.bodymaps_env
cd "$CODE_ROOT"
git fetch origin
git switch -c codex/dataset-delivery-373 --track origin/codex/dataset-delivery-373
```

For later updates:

```bash
source ~/.bodymaps_env
cd "$CODE_ROOT"
git switch codex/dataset-delivery-373

```

## B. Task One: Rename Existing Masks

Name audit on HPC:

```bash
python tools/dataset_delivery/audit_label_names.py \
  --data-root "$MASK_ROOT" \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --output-dir "$REPORT_ROOT/dataset_delivery/rename_audit"
```

After reviewing `candidate_matches.csv`, create a confirmed mapping file with this schema:

```text
source_name,target_name,status,reason,notes
```

Only `status=confirmed` rows execute. `pending_review` and `rejected` rows are ignored.

Validate mapping:

```bash
python tools/dataset_delivery/validate_rename_mapping.py \
  --mapping-file configs/dataset_delivery/organ_rename_mapping.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --report "$REPORT_ROOT/dataset_delivery/rename_mapping_validation.json"
```

HPC dry-run against read-only `MASK_ROOT`:

```bash
python tools/dataset_delivery/rename_anatomical_labels.py \
  --data-root "$MASK_ROOT" \
  --mapping-file configs/dataset_delivery/organ_rename_mapping.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --report "$REPORT_ROOT/dataset_delivery/rename_dry_run_report.csv" \
  --dry-run
```

Build the lightweight handoff directory:

```bash
python tools/dataset_delivery/build_delivery_packages.py \
  --mapping-file configs/dataset_delivery/organ_rename_mapping.csv \
  --dry-run-report "$REPORT_ROOT/dataset_delivery/rename_dry_run_report.csv"
```

Teacher server dry-run:

```bash
python rename_delivery/rename_anatomical_labels.py \
  --data-root /official/AbdomenAtlasPro \
  --mapping-file rename_delivery/organ_rename_mapping.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --report rename_delivery/dry_run_report.csv \
  --dry-run
```

Teacher server apply after confirming the dry-run:

```bash
python rename_delivery/rename_anatomical_labels.py \
  --data-root /official/AbdomenAtlasPro \
  --mapping-file rename_delivery/organ_rename_mapping.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --report rename_delivery/apply_report.csv \
  --apply
```

## C. Task Two: Generate Fixed 100-Case Missing Labels

Validate the manually confirmed organ gap table:

```bash
python tools/dataset_delivery/validate_gap_resolution.py \
  --gap-file configs/dataset_delivery/organ_gap_resolution.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --rename-mapping configs/dataset_delivery/organ_rename_mapping.csv \
  --report "$REPORT_ROOT/dataset_delivery/gap_resolution_validation.json"
```

Validate the fixed 100-case manifest:

```bash
python tools/dataset_delivery/validate_100case_manifest.py \
  --manifest configs/dataset_delivery/cases_100_manifest.csv \
  --report "$REPORT_ROOT/dataset_delivery/cases_100_manifest_validation.json"
```

Preflight:

```bash
python tools/dataset_delivery/preflight_100cases.py \
  --manifest configs/dataset_delivery/cases_100_manifest.csv \
  --gap-file configs/dataset_delivery/organ_gap_resolution.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --rename-mapping configs/dataset_delivery/organ_rename_mapping.csv \
  --teacher-entry run_medai_cli.py \
  --registry configs/model_registry.yaml \
  --output-root "$OUTPUT_ROOT/dataset_delivery/missing_labels_100" \
  --image-root "$IMAGE_ROOT" \
  --mask-root "$MASK_ROOT" \
  --code-root "$CODE_ROOT" \
  --output-dir "$REPORT_ROOT/dataset_delivery/preflight_100"
```

Two-case T4 smoke test without submitting Slurm:

```bash
RUN_DIR="$OUTPUT_ROOT/dataset_delivery/missing_labels_100_smoke"
python tools/dataset_delivery/run_teacher_case.py \
  --manifest configs/dataset_delivery/cases_100_manifest.csv \
  --gap-file configs/dataset_delivery/organ_gap_resolution.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --run-dir "$RUN_DIR" \
  --case-index 0 \
  --code-root "$CODE_ROOT" \
  --teacher-entry run_medai_cli.py \
  --registry configs/model_registry.yaml \
  --models "${MEDAI_TEACHER_MODELS:-epai_20250421,vsmtrans}" \
  --target-config configs/student_3d_prompt_target_organs.json \
  --device cuda

python tools/dataset_delivery/run_teacher_case.py \
  --manifest configs/dataset_delivery/cases_100_manifest.csv \
  --gap-file configs/dataset_delivery/organ_gap_resolution.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --run-dir "$RUN_DIR" \
  --case-index 1 \
  --code-root "$CODE_ROOT" \
  --teacher-entry run_medai_cli.py \
  --registry configs/model_registry.yaml \
  --models "${MEDAI_TEACHER_MODELS:-epai_20250421,vsmtrans}" \
```

```bash
  --taxonomy configs/student_3d_prompt_target_organs.json \
```

Full 100-case Slurm array:

```bash
export RUN_DIR="$OUTPUT_ROOT/dataset_delivery/missing_labels_100"
export CASES_100_MANIFEST="$CODE_ROOT/configs/dataset_delivery/cases_100_manifest.csv"
export ORGAN_GAP_RESOLUTION="$CODE_ROOT/configs/dataset_delivery/organ_gap_resolution.csv"
export TARGET_CONFIG="$CODE_ROOT/configs/student_3d_prompt_target_organs.json"
export MEDAI_TEACHER_MODELS="${MEDAI_TEACHER_MODELS:-epai_20250421,vsmtrans}"

sbatch --partition=<gpu_partition> --gres=gpu:T4:1 --mem=48G --time=08:00:00 --array=0-99%4 \
  slurm/teacher_missing_labels_100.sbatch
```

Summarize and rerun failures:

```bash
python tools/dataset_delivery/summarize_100case_run.py \
  --run-dir "$RUN_DIR" \
  --manifest configs/dataset_delivery/cases_100_manifest.csv \
  --output-dir "$REPORT_ROOT/dataset_delivery/run_summary"

FAILED_SPEC="$(cat "$REPORT_ROOT/dataset_delivery/run_summary/failed_array_spec.txt")"
sbatch --partition=<gpu_partition> --gres=gpu:T4:1 --mem=48G --time=08:00:00 --array="$FAILED_SPEC"%4 \
  slurm/teacher_missing_labels_100.sbatch
```

Validate all generated masks:

```bash
python tools/dataset_delivery/validate_generated_masks.py \
  --run-dir "$RUN_DIR" \
  --manifest configs/dataset_delivery/cases_100_manifest.csv \
  --gap-file configs/dataset_delivery/organ_gap_resolution.csv \
  --taxonomy configs/student_3d_prompt_target_organs.json \
  --output-dir "$REPORT_ROOT/dataset_delivery/validation_100"
```

Package the overlay:

```bash
python tools/dataset_delivery/package_dataset_overlay.py \
  --run-dir "$RUN_DIR" \
  --manifest configs/dataset_delivery/cases_100_manifest.csv \
  --validation-report "$REPORT_ROOT/dataset_delivery/validation_100/validation_report.csv" \
  --delivery-dir generated_labels_100cases
```

Safe preview:

```bash
rsync -av --ignore-existing --dry-run \
  generated_labels_100cases/ \
  /official/AbdomenAtlasPro/
```

Final merge after preview:

```bash
rsync -av --ignore-existing \
  generated_labels_100cases/ \
  /official/AbdomenAtlasPro/
```
